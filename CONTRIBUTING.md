# Suggesting a sample

This launchpad links to externally maintained voice samples. It does not host copies of their code.

## What fits

- Public repositories focused on Teams Phone Extensibility (TPE), Teams Phone Agent (TPA), or custom voice agents (for example, Voice Live or Foundry voice agents).
- For broad catalogs, link only the voice-specific folders, not the whole catalog.

## What does not fit

- Samples that only cover Azure Communication Services (ACS) calling or chat, with no TPE or voice-agent focus.
- Generic agent, bot, or speech catalogs without a voice-agent focus.
- Internal, confidential, or NDA-only links or content.

## What to include

Open an issue or pull request with:

| Field | Notes |
| --- | --- |
| Repository URL | `https://github.com/{owner}/{repo}` and any voice-specific folder links |
| Section | TPE, Supporting TPE tool, Voice Live and Foundry, or Templates and scenario demos |
| One-line description | What it does and any limits, such as "demo-grade" or "requires ACS" |
| Owner | The hosting account or organization. Add an author only if authorship is verified from a reliable source, never from the latest committer. |
| Created and last commit dates | From the GitHub repository and its default branch, in UTC |
| License | As detected on GitHub, or "None detected" |

Only label a sample as TPE or TPA when the repository shows direct support. Avoid claims about production readiness, endorsement, or product lifecycle that the source does not support.
